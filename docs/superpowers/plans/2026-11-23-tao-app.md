# Tao App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, offline mobile PWA at tao.tensor.group: virtual 64-stick draw → one of 81 passages with dense tap-to-open notes → timestamped journal with export / merge-import.

**Architecture:** Vanilla ES modules in `app/`, no runtime deps. Pure logic (`draw.js`, `journal.js`, `markup.js`) is unit-tested with `node:test`. Content is JSON in `app/data/`, produced by a two-pass agent pipeline and gated by `scripts/check-content.mjs`. Deployed as Cloudflare Workers static assets.

**Tech Stack:** HTML/CSS/JS (ES2022), Node 20+ (`node --test`), Python 3 + fonttools (font subsetting, dev only), wrangler.

**Spec:** `docs/superpowers/specs/2026-11-23-tao-of-power-app-design.md` (v2)

## Global Constraints

- No runtime dependencies, no framework, no bundler. Deployed folder = `app/` as committed.
- Never commit: `Tao of Power/`, `google-books-images/`, `taoofpower/`, `sources/raw/`, `docs/study/`.
- Creation agents never receive Wing's PDF, scans, OCR, or `tao.go`.
- Line values: 0 solid, 1 one break, 2 two breaks; `lines` array is bottom→top; `n = 1 + 27·L4 + 9·L3 + 3·L2 + L1`.
- Stick totals: 3→0, 4→1, 5→2.
- localStorage keys: `tao.journal.v1`, `tao.journal.snapshot`, `tao.draft.NN`.
- All user text via `textContent`; CSP `default-src 'self'; style-src 'self'; img-src 'self' data:`.
- Fonts OFL, self-hosted: EB Garamond, Noto Serif TC, LXGW WenKai TC.
- Colors: paper `#f4efe4`, ink `#1d1b18`, seal red `#a63a2a`; dark variant by `prefers-color-scheme`.

## Review Focus

1. Importing a backup older than a deletion → deleted entry must stay deleted (journal.test: `tombstone beats older import`).
2. Importing a malformed or foreign JSON file → journal unchanged, clear message (journal.test: `rejects invalid import without writing`).
3. App killed while typing → draft restored on reopen (manual check in Task 6; `draft` helpers unit-tested in Task 3).
4. Offline draw of a never-visited passage → opens from cache (Task 7 precache test: manifest lists all 81 passages + lexicon + fonts).
5. Tapping a character with no occurrence gloss → lexicon entry still shows (check-content: every Han char in `zh` has a lexicon entry).

- `castLine(rng?): { bundles: number[], total: 3|4|5, line: 0|1|2 }`.

### Task 3: Journal store (`app/js/journal.js`)

**Interfaces — Produces:**

- `addEntry(j, {passage, text, drawId?}, now): Entry`; `updateEntry(j, id, text, now)`; `deleteEntry(j, id, now)` (adds tombstone).
- `recordDraw(j, {passage, lines, bundles}, now): Draw`.
- `validate(obj): {ok: true, journal} | {ok: false, reason}`.
- `merge(local, incoming): Journal`; `toExport(j): string`; `exportFilename(date): "tao-journal-YYYY-MM-DD.json"`.
- `saveDraft(n, text, storage)`, `loadDraft(n, storage)`, `clearDraft(n, storage)`.
- Journal shape exactly per spec §6.

### Task 5: Content tooling (`scripts/`)

**Files:** `scripts/fetch-unihan.mjs` (downloads Unihan zip to `sources/raw/`, writes `sources/unihan.json` with kMandarin + kDefinition for every char in the text), `scripts/build-lexicon-base.mjs` (seeds `app/data/lexicon.json` entries `{py, def}` for every Han char of `sources/zh-wangbi.json`, never overwriting enriched fields), `scripts/normalize.mjs` (exports `NORMALIZE` table 爲→為, 强→強, … and `normalize(s)`), `scripts/check-content.mjs`, `scripts/copyright-guard.mjs`, `scripts/build-precache.mjs`, `scripts/subset-fonts.sh`.

- `check-content.mjs`: for each `app/data/passages/NN.json` present — schema keys (`n,title,theme,zh,rendering,notes,lenses,glyph,legge`), every `[[…|id]]` resolves in `notes`, every note has `kind` in the spec list, `normalize(join(zh.text))` equals normalized pinned source minus punctuation, every Han char has a lexicon entry, every lexicon `py` value ⊂ Unihan readings (tone-insensitive compare allowed only when flagged `"pyNote"`). Exit 1 on any failure; print a per-passage summary.
- `copyright-guard.mjs`: if `taoofpower/TaoOfPower.ocr.txt` exists, tokenizes words (lowercase, alnum) and fails on any shared 6-gram between it and all English strings in passages (allow-list file `scripts/ngram-allow.txt`), and on any term in `docs/study/wing/denylist.txt`. Skips with a notice if the OCR is absent.
- `build-precache.mjs`: writes `app/precache.json` `{version: <sha256 of all listed files, 12 hex>, files: [...]}` listing every file under `app/` except itself and `sw.js`.
- `subset-fonts.sh`: `pyftsubset` each TC font to the Han chars in data + Latin, output woff2 to `app/fonts/`.
- [ ] Test `tests/scripts.test.js`: `normalize('爲强')==='為強'`; precache lists `data/passages/01.json` once it exists.
- [ ] Run fetch + seed; commit `feat: content tooling and lexicon base`.

- About view: draw method + odds, sources & licenses (Wang Bi text, Legge, Unihan notice, Wiktionary CC BY-SA credit, font OFL), storage warning (Brave Shields / Safari).
